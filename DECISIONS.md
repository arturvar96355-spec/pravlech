# DECISIONS — «Правильное лечение»

Решения, принятые при сборке концепта там, где в промпте была развилка или не хватало данных.

## Конфликты в ТЗ
| Тема | Решение |
|---|---|
| Blur при reveal: Б6 разрешает 6 px, А8.4 запрещает | Blur нет совсем. Появление — только `opacity` + `translateY`. Часть А приоритетнее: сайт медицинский, он должен быть спокойным. |
| TypeScript | Установлен `typescript@5` (strict). Ветка 7.x (нативная) на момент сборки новая и не проверена с Next 16. |
| Версия Next | `next@16.4.2`: `output: 'export'` собирается без правок. |
| `@hookform/resolvers` | Не используется: версия 6.0 тянет за собой цепочку необязательных peer-зависимостей (`ERESOLVE`). Вместо неё — свой тонкий resolver на `zod` (`BookingDrawer.tsx`). |
| Шрифты | Rubik (заголовки, 500/600) + Onest (текст, 400/500) через `next/font/google`, `subsets: ['latin','cyrillic']`, `display: 'swap'`. База текста 17 px, с 768 px — 18 px. |
| Рейтинг | Пишем «5.0» (как в ТЗ), а не «5,0». |

## Данные и заглушки
- Названо **пять** специалистов: Варданян (кардиолог), Ермошкина (невролог), Салькаев и Витушкина (ЛОР), Гоар (медсестра процедурного кабинета). Гоар — не врач, поэтому у неё отдельная подпись и услуга «анализы».
- На сайте клиники **9 врачей**. Известно четыре, поэтому добавлено пять карточек-заглушек `[имя — перенести с сайта]`. Вместе с Гоар в сетке 10 карточек.
- Цитат нет ни одной. Везде стоит `[цитата из отзыва на Яндекс Картах — подобрать]`: 5 слотов на специалистов + 3 общих + 4 в блоке «Почему возвращаются». Выдуманных отзывов нет.
- Цены только из ТЗ: терапевт 3 500 ₽, кардиолог 4 500 ₽, ЭхоКГ 4 000 ₽, УЗИ 2 000–3 000 ₽ (в конструкторе по умолчанию ≈ 2 500 ₽). Приём невролога и ЛОР, ЭКГ, анализы, справки — заглушки.
- Скидка −10% на анализы заложена в расчёт (`CheckupBuilder`), но пока цена анализов неизвестна, вместо суммы показывается заглушка `[сумма — после утверждения прайса]`. Как только клиника даст цены, скидка посчитается сама (`weekendDiscount: true` в `content/checkup.ts` и `content/prices.ts`).
- Пресеты «Сердце» и «После 40» собраны только из позиций с известной ценой плюс заглушки. Пометка `[состав — согласовать с клиникой]`.
- Для врачей перечень «С чем обращаются» — общий по специальности (`content/doctors.ts`, `scopeBySpecialty`), без диагнозов. Помечен как «согласовать с врачом».
- Ссылка на Яндекс Карты ведёт на поиск по адресу. Точная ссылка на карточку организации — заглушка.
- Схема проезда — нарисованная SVG-схема без внешних сервисов, «не в масштабе».

## Запись
- WhatsApp-номера нет → `site.whatsapp` пуст. В этом случае после отправки формы показывается текст заявки, кнопка «Скопировать текст» и «Или позвоните: +7 (495) 287-64-48». Когда номер появится в `content/site.ts`, `lib/booking.ts` начнёт формировать `wa.me`-ссылку и откроет мессенджер.
- Слоты — только для показа (каждые 30 минут по режиму дня, сегодня — не раньше чем через час). Реального расписания нет: `[интеграция с МИС — после запуска]`. На экране так и написано: «Ориентировочно — администратор подтвердит время».
- Данные формы никуда не отправляются и не сохраняются. Они формируют текст, который человек сам отправляет в мессенджер или читает по телефону. Это снимает вопросы по хранению персональных данных в концепте (здоровье — специальная категория по 152-ФЗ). Для боевого сайта оператором ПД будет клиника; политику пишет клиника (`/privacy` — заглушка).
- «Сейчас открыто» считается на клиенте по `Europe/Moscow`. В статической HTML стоит нейтральный текст «Пн–пт 8:00–21:00», чтобы не было расхождения при гидрации.

## Анимации и производительность
- Hero: заголовок по строкам чистым CSS (стартует до гидрации — иначе LCP уезжал на 2+ секунды). Кардиограмма строится по реальной ширине экрана и прорисовывается через `pathLength` за 1,4 с, потом проявляется подчёркивание кнопки.
- Сцена «Как проходит приём»: GSAP ScrollTrigger, `pin` ≈ 220% высоты экрана + `scrub`. На ширине < 768 px — вертикальные карточки без pin.
- GSAP, ScrollTrigger и Lenis подгружаются лениво после первой отрисовки (`lib/scroll.ts`). Окно записи — `next/dynamic`, `ssr: false`.
- `prefers-reduced-motion`: Lenis и ScrollTrigger не запускаются, float, пульс и появление строк отключены, reveal без сдвига.
- Lighthouse (мобильный, симуляция, локальная сборка): Performance ≈ 88–91, Accessibility 98–100, Best Practices 100. SEO 63 — это из-за `noindex`, как и предполагалось в ТЗ.

## Фото
- Хосты Unsplash и Pexels из окружения сборки недоступны, поэтому стоковых фото нет. Вместо них — нарисованные SVG-иллюстрации (кабинет, шаги приёма, значки направлений). Люди клиники — монограммы с подписью `[фото — от клиента]`. `content/credits.ts` готов к тому, чтобы вписать источники, как только фото появятся.
- OG-картинка (`public/og.jpg`, 1200×630) собрана из названия и фирменных форм.
